# Student Management System — Minor Project

## Project overview
A beginner-friendly front-end project made with HTML, CSS, and JavaScript. It lets you register students, view a student table, and search by student name or roll number. Data is saved in the browser using localStorage.

## Files
- `index.html` — page structure and registration form
- `style.css` — blue-and-white responsive design
- `script.js` — form validation, adding students, searching, and browser storage

## Run in VS Code
1. Extract the ZIP file to a folder.
2. Open VS Code.
3. Select **File → Open Folder** and choose the extracted `student_management_system` folder.
4. Open `index.html`.
5. Right-click inside the file and choose **Open with Live Server** if the Live Server extension is installed.
6. If you do not have Live Server, open the folder in File Explorer and double-click `index.html`.

No installation, backend, or database is required.

## How to test
1. Fill in the student registration form.
2. Click **Add Student**.
3. Confirm the student appears in the table and the dashboard counts update.
4. Search by name or roll number.
5. Try registering the same roll number twice; the form will show a validation message.

## Important limitation
This is a front-end demo. Data is stored only in the browser on the current device and browser profile. It is not connected to a server or shared college database.

## Short viva explanation
“This project is a Student Management System developed using HTML, CSS, and JavaScript. HTML creates the structure and form, CSS provides the responsive blue-and-white design, and JavaScript validates the input, adds student records to the table, and filters records during search. I used browser localStorage to keep the records available after refreshing the page. This is a front-end prototype, not a complete database-backed system.”
